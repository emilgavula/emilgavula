## About
 
I'm a **Cloud Solutions Architect at Microsoft**, designing and delivering secure, scalable, and operable solutions on Azure. My work centers on networking, governance, security, and infrastructure automation — with a bias toward pragmatic architecture that balances reliability, cost, and operational simplicity.
 
**What I focus on**
 
- Enterprise networking and cloud connectivity
- Governance, policy, and security posture
- Infrastructure as code and automation at scale
- AI-enabled operations and SRE practices
